SQBS - Quiz Bowl Tournament Statistics Recording Program
========================================================
Installation:
 SQBS is single file application. The file can be put in Applications
folder, left on Desktop, or placed where ever is preferred. It is suggested that
only 1 copy of SQBS be stored to prevent possible OS confusion over help files.

Uninstall: 
 Drag SQBS file to the trash.

File Difference with SQBS (Windows):
 SQBS (OS X version) saves files either in OS X format or Windows compatible
format. OS X format stores the new bonus conversion setting "Auto with Bouncebacks"
and may contain other differences from Windows compatible format. If you are
submitting tournament files or sharing with users not using OS X version of
SQBS, save as Windows compatible format.
OS X format files can also be opened directly by double clicking on the file
(versus having to use Open command after launching application).
