Game Reports

The Games report can be selected through the “Reports” menu or by pressing ⌘G (if not currently in the “Reports” tab, the tab will be selected). If round numbers were used in Game Entry, games are separated by round. If packet names (under the Settings tab) are entered, the packet names will appear instead of round numbers. The report then lists the score of each game, with overtime games denoted with “OT” after the score.
