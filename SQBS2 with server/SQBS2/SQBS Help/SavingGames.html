Saving, Navigating and Deleting Games

Hit “Save” to save any entered data. Note that this does not save the game data to the tournament file (done with Save command, or ⌘S), just the progress on the Game Entry screen in case the user needs to go to another screen.

To create a new game, go to the most recent game and hit the up arrow near the “Goto game” field. This creates a new game with an ID one higher than the previous game.

The user can also use the up and down arrows to navigate through the games in order. Number to the right of up‐down stepper indicates the current game index out of total games entered. Both numbers are zero‐based, meaning first game is 0. Total game count is 1 greater than number displayed as the total. Moving to another game also saves the data of the game that the user is leaving.

To delete the game currently on the Game Entry screen, click “Delete”. A warning will appear.
