Team Standings

The Team Standings report can be selected through the “Reports” menu or by pressing ⌘T (if not currently in the “Reports” tab, the tab will be selected). If there are divisions set up for the tournament, teams will be separated by division. Teams are then ranked based on the method chosen under “Sorting” in the “Settings” tab. Depending on what options were selected when the tournament was created, the possible statistic headings are:
W:Wins
L:Losses
T:Ties
Pct:Fraction of games won
PPG:Points per game
PAPG:Points against per game
Mrg:Difference of points for and points against (negative if opponents scored more)
10, etc:Number of responses for each different point value
TUH:Tossups heard
P/TU:Points per tossup heard
P/N:Ratio of powers (first column) to negs (third column)
G/N:Ratio of gets (all columns except third) to negs
Ltng:Lightning round points
BHrd:Bonuses heard
BPts:Bonus points
P/B:Bonus points per bonus
BBHrd:Bouncebacks heard
BBPts:Bounceback points
P/BB:Bounceback points per bounceback
