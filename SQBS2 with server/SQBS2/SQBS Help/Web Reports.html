Web Reports

Web reports are a set of web pages that include the information found in the “Reports” tab, as well as more detailed information about teams, players, and rounds. To generate a web report, press the “Web Reports” button on the menu bar, select “Full Web Report” under the “Reports” menu or press ⌘W. A save window will appear, asking the user to choose a name and location for the generated HTML pages.

Note that the name will have suffixes appended based on options in the Settings tab; it is recommended to save the web report as a short name with simple characters and no extensions (such as “oqt2010”). The generated web pages can then be opened in a web browser or uploaded to a website.
