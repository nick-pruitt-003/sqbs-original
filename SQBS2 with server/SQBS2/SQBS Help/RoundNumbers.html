Rounds and Game ID

If the user wishes to track round information in the Web Reports, round numbers must be entered in the “Round” field. The numbers must be whole numbers starting with 1 to have meaningful results. The Game ID is a code for an individual game for easier searching via the “Goto game” field. By default, Game ID starts at 0 and incrementally increases by 1, but other short codes, such as “R1G2”, can be used. Once a Game ID is saved, the game can be recalled by typing the ID in the “Goto game” field and hitting Return.
