Game Entry

Select the “Game Entry” tab to enter game resutls. Most the fields in the form should be self–explanatory and align with tournament match score sheets. Complete game results are not necessary to save a game, allowing missing results to be entered later. The minimum information required before saving a game is that Team A and Team B are selected. Saving a game is done using the Save button, or is done automatically if you advance / backup to the next game using the game stepper beside the “Goto game” text field.
