Choosing Players

Once teams have been selected, up to 8 (depending on the size of the roster) player slots appear. By default, the names appear in the order listed on the roster entry, and the first names are listed with 1 game played, depending on the value given for the maximum number of players per side in the Tournament Setup screen. If substitutions were made, the games played can be manually overridden with 0.5 (for halftime) or a fraction of the total number of tossups heard in the game (such as 10/21).
