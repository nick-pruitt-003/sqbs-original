Roster Entry

The bottom half of the Tournament Setup screen contains the roster of players. To manually enter teams, press “+” to make a new team. The team name, exhibition status, division (if applicable) and player names can then be entered. The fields can be accessed left-to-right by pressing Tab. To delete a team; highlight the row by selecting it; press “–” button. Note that a warning will appear.

Teams can be sorted alphabetically by Team Name (ascending or descending) by clicking on the Team Name column header.

Rosters can be imported from a text file (or saved tournament file) by clicking “Import” from the top toolbar. Select the file, and the imported roster should appear in the fields, overriding any teams entered prior. The text file should have, on separate lines in order, the team name, the division name (if applicable) and the player names (up to 12). Teams should be separated by a line with a period, and the end of the file should have a line with a tilde (~). For example, a tournament with two teams and divisions should appear as the examples below.

You may add or delete division names, or correct spelling errors any time before entering game information. Changes made in the divisions text field will not show up in the team entry table until a save of division names is done. Unchecking “Using Divisions” once games are entered is allowed, however all division assignments for team is deleted (warning provided). Once games are entered, division names can be added. Deleting or changing names can be done, however verify that each team is correctly assigned the correct division name.

Once games are entered, spelling errors for players names can be corrected, however players cannot be added, deleted, nor their order changed.
