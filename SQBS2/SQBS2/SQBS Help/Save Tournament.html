Saving a Tournament

Once any data has been entered for a tournament, the file can be saved. Clicking “Save” on the top toolbar or selecting “Save” from the File menu, or ⌘S will open the save dialog box, where you can choose a name and save location for the file.

The save dialog box also allows the user to save the tournament in a file compatible with the Windows version of SQBS. Once the file has been saved for the first time, saving will update the file without opening the save dialog box.

To save the file under a different name or location, select “Save As” from the File menu, or &uparr;⌘S.
