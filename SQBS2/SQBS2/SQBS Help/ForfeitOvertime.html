Overtimes, Ties and Forfeits

If a games goes to overtime, check the box labeled “Overtime”. An overtime field appears on each side, where the user can enter the number of “gets” (positive tossups) a team earned in overtime. This value is then subtracted from the number of bonuses heard (if tracked automatically) so that bonus conversion remains consistent. If overtime is resolved simply by a negative point change, keep that neg amongst the individual tallies and leave the overtime fields blank. If tournament rules allow a game to finish as a tie, the result will appear as such on final reports. If a game is a forfeit, select the “Forfeit” checkbox. Team A will be credited with a win over Team B, with no further scoring information kept. If the winner is listed on the Team B side, simply hit the “Team Swap” button to correct it.
